TornTools enhances the Torn.com experience with a wide range of quality-of-life improvements, including API
integrations, notifications, advanced filters, UI enhancements, and automation helpers.

Available on [Chrome](https://chrome.google.com/webstore/detail/torn-tools/hjpaapdjcgbmeikfnahipphknonhlhib),
[Firefox](https://addons.mozilla.org/en-US/firefox/addon/torn-tools/), and
[Edge](https://microsoftedge.microsoft.com/addons/detail/arxivutils/jpjcipoihjdechmeakebibhfhnmgflhj).

## Key Features

- **Notifications** — energy, nerve, travel, cooldown, and event alerts
- **Advanced Filters** — hospital, jail, travel market, faction members, and more
- **API Integration** — auto API key fill, TornStats, YATA, and other services
- **UI Improvements** — sidebar enhancements, collapsible areas, custom links
- **Quick Actions** — one-click crimes, drug details, quick items
- **Trade & Bazaar** — item values, bazaar worth, trade timer
- **Faction Tools** — member filters, OC timers, bank, armory management
- **Chat Enhancements** — autocomplete, highlights, search, resizable chat
