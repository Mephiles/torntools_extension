TornTools is available on all major browser extension stores.

## Browser Stores

| Browser | Link                                                                                                          |
|---------|---------------------------------------------------------------------------------------------------------------|
| Chrome  | [Chrome Web Store](https://chrome.google.com/webstore/detail/torn-tools/hjpaapdjcgbmeikfnahipphknonhlhib)     |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/torn-tools/)                                 |
| Edge    | [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/arxivutils/jpjcipoihjdechmeakebibhfhnmgflhj) |

## API Key Setup

Many features require a Torn API key. To set one up:

1. Go to [Torn API page](https://www.torn.com/api.html)
2. Generate an API key with limited access 
3. Paste the key into TornTools
